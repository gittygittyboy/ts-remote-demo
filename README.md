# TS Remote · Demo

Demo der mobilen Bedien-App fuer die Trading Software, zum Ausprobieren auf dem iPhone.

- **Nur Testdaten.** Die Demo spricht mit keinem Server; alle Antworten kommen aus einem kleinen
  Demo-Server im Browser. Es gibt keine echten Orders, keine Adressen und keine Zugangsdaten.
- Kopplungscode und PIN beliebig; die PIN `000000` zeigt den Ablauf bei falscher PIN.
- Installieren: in Safari oeffnen, Teilen -> "Zum Home-Bildschirm".

Diese Seite enthaelt nur den fertigen Build (automatisch erzeugt), keinen Quellcode.
